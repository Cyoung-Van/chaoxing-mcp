# 实现来源与验证边界

`chaoxing-mcp` 0.2.0 根据产品需求与平台接口观察重新实现，原创代码按 [MIT License](../LICENSE) 发布。本文件记录实现过程、外部依赖和已有证据的范围。

## 实现过程

协调者结合此前项目上下文编写了 [实现契约](IMPLEMENTATION_CONTRACT.md)，描述产品行为、数据结构、错误语义，以及平台互操作所需的 URL、DOM 和 JSON 接口事实。

平台解析、采集和浏览器传输部分由独立启动、使用新上下文的开发代理实现。它们仅阅读该契约和本仓库新建模块，没有读取旧实现、审查归档、vendor 快照或相关第三方项目的源码。协调者独立编写通用编排、存储、查询、CLI 与 MCP 部分。因此，隔离范围指这些平台适配实现者，并不涵盖协调者编写契约时已知的项目背景。

发布树不包含相关项目的原始源文件或旧版适配快照。平台适配模块按本仓库实现契约重新编写；本次来源检查未发现需要保留的非平凡第三方实现片段。公开测试样例根据接口事实重新构造，不包含真实账户数据。接口事实、标准调用样板、代码相似度以及开发过程隔离均不单独构成许可判断依据。

## 相关项目与依赖

OpenCLI、chaoxing-list 是相关方向与灵感来源。提及它们不表示作者认可本项目，也不声明这些项目采用 MIT 许可。

本项目通过普通依赖提供 MCP 协议、HTML 解析与输入校验等通用能力。依赖及锁定版本见 [package.json](../package.json) 与 [package-lock.json](../package-lock.json)，每项依赖保留自己的许可证。

平台 URL、字段名、页面标签与响应结构用于互操作，可能随平台版本、学校配置或账户权限改变。本项目是非官方工具；MIT 许可不授予超星商标、平台服务或课程内容的额外使用权。

## 公开数据与验证范围

公开仓库包含源代码、依赖清单、文档和合成测试。快照、浏览器配置、真实响应、截图、账户标识及带访问参数的链接应保留在本地。默认运行目录 `.local/` 已忽略；改用其他路径时，需要重新检查忽略规则与提交内容。

合成测试只验证给定样例和边界条件。真实账户验证需要另行记录日期、范围、成功来源和失败情况，不能根据测试通过或已知接口地址推断。

非空任务引擎目前只有功能契约及合成数据层面的验证依据，尚无真实账户非空任务包、分组或学习计划的通过声明。发布检查结果以 [测试与验证](TESTING.md) 中实际填写的证据为准。

“采集完整”始终限定于一次快照的课程筛选、模块、数量限额与已实现数据源。未知、失败或无法读取的内容不代表不存在，项目也不承诺发现全平台的所有任务。

后续如引入第三方源文件或代码片段，应核对许可、保留归属声明，并更新本文件。
